AI-powered certification exam prep platform. Study smarter with AI-generated questions, smart content, and an exam coach — free forever.

## Features

- **AI Study Guide** — Domain snapshots, key concepts, and quick quizzes generated by Llama 3.3 70B
- **Practice Exams** — Full, mini, and domain-drill modes with cert-accurate question weights
- **AI Tutor** — Chat with a cert-specific exam coach anytime
- **Progress Tracking** — Per-cert domain progress with readiness scores
- **Exam History** — Scoped per certification with domain breakdowns
- **Question Bank** — Save and retake generated question sets instantly

## Local Development

```bash
npm install
cp .env.local.example .env.local  # add your env vars
npm run dev
```

Required env vars:
```
VITE_WORKER_URL=https://your-worker.workers.dev
VITE_GITHUB_CLIENT_ID=your-github-oauth-app-id
```

## Deployment

Pushes to `main` automatically deploy to GitHub Pages via GitHub Actions.

Worker deployment:
```bash
cd worker
npx wrangler deploy
```
